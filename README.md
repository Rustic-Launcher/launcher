# Rustic Launcher

> **Rustic is a social game platform, powered by the Horizon engine** <img src="https://raw.githubusercontent.com/horizon-rust/horizon/main/docs/media/logo.png" alt="Horizon" width="16" height="16">

The desktop app of Rustic, built on **[Horizon](https://github.com/horizon-rust/horizon)** (the MIT-licensed Rust
rewrite of the 26.3 Java game) with a social, cosmetics-first experience: instances and content
(mods, packs, shaders), Microsoft sign-in with an ownership check, friends and parties, cosmetics,
and creating and managing **Rustic Server** servers (local, on your own VPS over SSH, or through the
Rustic Relay) with their `.rplugin` plugins.

> Unofficial. Not affiliated with Mojang or Microsoft. No game code or assets are included or
> downloaded from third parties: owning the game is mandatory, and game files come from the
> player's own install or, for a verified owner, from Mojang's servers.

## Repository

| Path | What |
|---|---|
| [`apps/launcher`](apps/launcher) | The Tauri 2 desktop app (React + TypeScript UI, `src-tauri/` Rust side) |
| [`packages/ui`](packages/ui) | `@rustic/ui`, the design system (tokens, components, 3D player viewer), with Storybook |
| [`packages/cosmetics-format`](packages/cosmetics-format) | `rusticmc-cosmetics-format`, the cosmetics package format (Horizon-convertible) |
| [`crates/rusticmc-launcher-core`](crates/rusticmc-launcher-core) | Paths, config, logging, shared launcher plumbing |
| [`crates/rusticmc-auth`](crates/rusticmc-auth) | Microsoft sign-in (PKCE + device code), ownership gate, OS keychain |
| [`crates/rusticmc-instances`](crates/rusticmc-instances) | Horizon installs, downloads, preparation and launch |
| [`crates/rusticmc-content`](crates/rusticmc-content) | Content sources, installs ledger, fair-play filter |
| [`crates/rusticmc-servers`](crates/rusticmc-servers) | Local servers, plugins, DNS (Porkbun and bring-your-own domain), invite codes |
| [`crates/rusticmc-hosting`](crates/rusticmc-hosting) | VPS hosting over SSH (install, service unit, firewall, backups) |
| [`crates/rusticmc-tunnel`](crates/rusticmc-tunnel) | Tunnel client for the Rustic Relay |
| [`crates/rusticmc-api-client`](crates/rusticmc-api-client) | Typed client of the Rustic Cloud API (`openapi.json` + generated methods) |
| [`client-mod/rustic-companion`](client-mod/rustic-companion) | In-game companion and the "Rustic edition" client (links Horizon, see below) |

`crates/rusticmc-api-client`, `crates/rusticmc-tunnel`, `packages/cosmetics-format` and
`packages/ui` are also used by the Rustic Cloud services and the website, which depend on this
repository at a pinned commit.

## Build and run

Needs Node 22.12+, pnpm 10 (`corepack enable`), Rust 1.95+. On Linux, Tauri's system libraries:

```sh
sudo apt-get install -y libwebkit2gtk-4.1-dev libappindicator3-dev librsvg2-dev patchelf \
  libssl-dev libdbus-1-dev pkg-config
```

```sh
pnpm install
pnpm dev          # the UI in a browser with the mocked IPC layer (http://localhost:5173)
pnpm tauri:dev    # the desktop app
pnpm tauri:build  # installers (apps/launcher/src-tauri/target/release/bundle)
pnpm storybook    # the design system
```

Production builds read `apps/launcher/.env.production` (the public Rustic Cloud hosts); any real
environment variable overrides it (`VITE_CLOUD_URL=http://localhost:8080` for a local cloud).

## Test

```sh
cargo fmt --all --check
cargo clippy --workspace --all-targets -- -D warnings   # needs apps/launcher/dist: run `pnpm build` once
cargo test --workspace
pnpm lint && pnpm typecheck && pnpm test
pnpm e2e          # Playwright journeys against the mocked IPC layer
```

## The Rustic edition client (`client-mod/rustic-companion`)

Its own Cargo workspace: it links Horizon's game crates by path and uses Rustic's Horizon patches.
Clone the server repository next to this one and prepare Horizon there:

```sh
git clone https://github.com/Rustic-Launcher/server ../server
cd ../server && git submodule update --init horizon && python scripts/patches.py apply && cd -
cargo build --manifest-path client-mod/rustic-companion/Cargo.toml --profile fast
```

It is not part of CI (it builds the whole game). `client-mod/rustic-companion/ci/rustic-edition.yml`
is a sketch of the release workflow.

## Cloud API contract

`crates/rusticmc-api-client/openapi.json` and `src/generated.rs` are generated by the Rustic Cloud
API (`gen-openapi`) and updated here with each release; the TypeScript types come from the same file
(`pnpm --filter @rustic/launcher gen:cloud`).
