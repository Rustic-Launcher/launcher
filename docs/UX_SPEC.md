# Rustic Launcher: UX specification

Owner: spec. Implemented by the frontend owner (`apps/launcher`, `packages/ui`). Tokens:
[PALETTES.md](PALETTES.md) (Ember default). Wireframes (low fidelity, neutral, original):
[`wireframes/`](wireframes/), regenerated by `python docs/tools/wireframes.py`.

Principles: **play in ≤ 2 clicks**, calm (no dark patterns: the Store is never pushed), honest compatibility, social
everywhere but private by default, everything reachable by keyboard. Inspiration from Lunar Client is limited to
*organisation* (title bar + icon rail + Launchpad with a big centred launch button + detachable Social window, step 1b);
no name, text, icon, asset, artwork or accent colour is copied.

## 1. App shell (every page) — revised in step 1b (ADR 0028)

Organisation follows Lunar Client's *layout and interaction patterns* at the user's request (brief at the end of
`launcher/AGENTS.md`); name, logo, art, texts, icons and the green accent are never reused. Surfaces are neutral
anthracite (blue-grey near-blacks, flat 1 px borders); the accent stays the palette's (Ember by default).

- **Custom title bar** (44 px, frameless window, drag regions on empty space): product switcher **Rustic ▾**
  (Rustic Launcher, Rustic Server docs), back / forward, **breadcrumb** (`Launchpad`, `Versions / Horizon`,
  `Explore / Mods`, `Servers / Featured`, `Settings / Privacy & data`…). Right: **search** icon button (`Ctrl+K`
  command palette), **notifications** (bell, unread dot), **social** (unread badge = unread chats + incoming
  requests; opens the Social window), **account pill** (avatar + name + caret: Microsoft profiles, Rustic account,
  add/manage/sign out), **"N instances running"** pill (popover: running games with Stop, background downloads with
  progress and Cancel; a 1 px progress line runs along the pill's bottom while downloading), then window controls
  (minimise, maximise/restore, close). The browser build hides the window controls.
- **Left rail** (64 px): plain outline icons, no labels, tooltips with name + shortcut (`Alt+1`…`Alt+6`); order
  **Launchpad, Versions, Explore, Servers, Locker, Store**; separator; bottom **+** (new profile) and **Settings**
  (`Alt+,`). Active item: a small accent bar on the rail's left edge. Roving focus with arrows / Home / End.
- **Content**: one rounded panel (`radius.xl`, 1 px border) holding the page; dense two-column layouts with a right
  column where the reference has one (Launchpad, Versions, Explore).
- **No bottom bar, no docked friends panel.** PLAY lives on the Launchpad hero (big centred LAUNCH button) and on
  every Versions cover and detail panel. Friends live in the Launchpad column and the Social window.
- Toasts bottom-right, max 4, auto-dismiss 5 s (pausable), never for marketing.

PLAY / LAUNCH states (Launchpad hero, Versions detail): **Launch game** · **Update & launch** (one click updates then
launches) · progress fill with the step text, **Cancel** on hover/focus · **Stop game** while running · disabled
when no instance. Line 2 always shows "Horizon x.y (Rustic edition)"; the caret switches instance.

### 1.1 Social window — [18-social-window.svg](wireframes/18-social-window.svg)

A separate, detachable frameless window on desktop (label `social`), an in-app overlay in the browser build. Header:
mark, "Social", online count, window controls. Left: **Friends / Chats** tabs; Friends = search + add friend, party
card (members, pending invites, leave), requests (accept / decline / cancel), Online and Offline groups with presence,
activity line, Join (when joinable), menu (send a message, invite to party, favourite, remove with confirmation).
Chats = searchable conversation list with unread counts. Right: the conversation (messages, composer, 2000 chars) or

## 2. States (all pages)

| State | Rule |
|---|---|
| Loading | Skeletons with the real layout (cards, rows), shimmer 1.2 s loop (static tint under reduced motion); no spinners for > 300 ms content, spinner only inside buttons |
| Empty | Short sentence + one primary action + optional illustration (original art), e.g. Servers: "Host a world for your friends in 3 steps" → Create server |
| Error | Inline banner in the affected area: what failed in plain words, **Retry**, **Copy details** (host, status, time, request id); never a blank page; offline banner when the network is down (cached data still shown, actions that need network disabled with a tooltip why) |
| Disabled | `text.disabled`, no hover, tooltip explaining why and how to enable (e.g. "Sign in to buy", "Coming soon") |
| Partial | Lists render what is available; failed sources show a chip "Modrinth unavailable · Retry" |

## 3. Motion and accessibility

- Durations 150 (hover/press), 200 (popovers, tabs), 250 ms (pages, modals, Social overlay); `ease.standard`; exits
  at 80 %. Page change: 8 px rise + fade. No looping motion except progress, skeleton, and the 3D idle.
- `prefers-reduced-motion` or Settings › Accessibility › Reduce motion: fades ≤ 100 ms only, no auto-rotate.
  "Reduce transparency" swaps glass for solid `bg.3`.
- WCAG 2.2 AA: contrast verified (PALETTES.md); focus ring 2 px + 2 px offset on every interactive element; targets
  ≥ 32 × 32 px (24 px minimum per 2.5.8, we exceed it); full keyboard support (Tab order follows layout: rail → top
  bar → page; `F6` cycles regions); Radix primitives for dialogs, menus, tabs (focus trap,
  `Esc`, ARIA); skip link "Skip to content"; landmarks (`nav`, `header`, `main`, `aside`, `footer`); live region for
  download progress (polite, throttled to 10 % steps) and errors (assertive); every icon button has an accessible name;
  colour is never the only signal (badges carry text + icon); text scales 90-130 % without clipping; the 3D viewer has
  buttons for rotate/zoom/reset and a text list of what is worn.
- **Shared visual language with the website (2026-11-10, web ADR 0141)**: Ember palette by default (accent
  `#FF6A00`, amber `#FFB020`, warm near-black neutrals), 18 px card radius, pill buttons; the other two palettes
  keep working. **Premium cards** (`PremiumCard` / `PremiumGrid` in `@rustic/ui`): layered glass with grain and an
  inner highlight, 1 px gradient edge (accent → amber → transparent), conic sweep on hover, one cursor spotlight
  shared across a grid, 3D tilt with depth layers (pointer devices ≥ 900 px only), accent bloom, mechanical
  settle; variants default / featured / accent / compact; amber focus glow; no tilt or sweep with reduced motion.
  Used on the Launchpad featured strip and the Servers featured list; forms and dense lists stay on the calm
  `Card`.
- **Launcher restyle (2026-11-11, ADR 0143)**: every page has a mono uppercase eyebrow and a title with
  one serif-italic accent word (Launchpad "Welcome *back*,", Versions "Your *profiles*", Explore "Find
  your next *mod*", Servers "Play on *servers*", Locker "Your *locker*", Store "The *store*", Settings
  "Your *settings*", wizard "Create a *server*"); cards are premium surfaces (`Card` / `.rx-surface`:
  gradient edge, grain, pointer spotlight); warm grain background with an ember glow, dot-grid content
  panel; page blocks enter blur → sharp (420 ms, 40 ms apart). While a game runs (`html[data-paused]`)
  or the window is hidden, every animation rests: CSS animations, entrances, the 3D viewers, the hero
  light. Organisation, navigation and shortcuts are unchanged.
- **Light stream** (the website's WebGL ribbons, shared as `@rustic/ui/light-stream`): only behind the Launchpad
  hero, at a calm intensity, loaded after first paint; **paused** while an instance is running, while the window
  is hidden or minimised, in battery saver (discharging and ≤ 20 %); never started with reduced motion (the hero
  art stays alone).

### 4.3 Explore (Content) — redesigned 2026-11-13 (ADR 0156); older wireframes: [03](wireframes/03-content-browse.svg), [04](wireframes/04-content-detail.svg)

- **Header**: title, then the tabs **Discover · Browse · My content** (FR: Découvrir · Parcourir · Mes contenus);
  one toolbar under it: the **kind selector** fused into the search field (Mods, Modpacks, Resource packs, Shaders,
  Data packs; Plugins in a "For a Rustic Server" group) and **"Installing into: <instance or server> ▾"** (hidden
  for modpacks: they become profiles). Everything is in the URL (`tab`, `kind`, `q`, `target`, Browse filters).

- **Discover**: a large **featured carousel** (picture or generated art, name, author, tags, summary, Install + View,
  compatibility; visible arrows, dots, pause/play; rotation stops on hover/focus, while a game runs, and never starts
  with reduced motion; Left/Right/Home/End), then **themed rows** of visual cards (picture, icon, name, author,
  downloads, compatibility): New · Popular on Horizon · Verified by Rustic · For <target> · From the community, each
  with **See all** (Browse with that row's filters). Flagged or refused (fair play) projects are never promoted; an
  empty row is hidden.
- **Browse**: result count; sort (relevance, downloads, newest, updated); **Filters** panel (sources Horizon /
  Modrinth / Rustic, compatible only (on by default), verified by Rustic only, price all/free/paid, categories) with
  removable chips for active filters; **list / grid** toggle (remembered). Rows: thumbnail, name, "by author",
  verified, summary, compatibility badge (Builds on your Horizon / Compatible / Incompatible: reason; native mods:
  **Builds on your PC**), source, price, category chips, downloads, updated, size, game and latest version; **View**
  and **Install / Installed / Update / Coming soon (paid) / Build and install (native, disabled until the launcher
  compiles them)**. **Load more** while a source has more (`has_more`). Data packs ask for a world on Install.
- **My content**: installed on the target (enable switch, update, remove with confirmation; servers link to their
  page), then, signed in, **My library** (Rustic library: View, Install, remove) and **My creations** (status:
  public, unlisted, private, waiting for review, rejected, taken down; **Manage** and **Publish on the website** open
  rustic-launcher.com). Signed out: one card to sign in.
- **Project page**: banner hero (first screenshot or generated art), icon, name, verified, author · licence · source,
  badges (compatibility, source, verified, side, shader format, price), target picker, Report, **Add to my library**
  (free Rustic projects, signed in), Install. Paid: the price and "Coming soon", never a buy button. Tabs Description
  (sanitised Markdown), Gallery, Versions (channel badges, Horizon builds, compatibility, per-version install),
  Changelog, Dependencies, Compatibility (native mods explained); sidebar with stats, categories, links and the
  project's page on the website. Unknown, private or taken-down projects: "This project is not available".
- **Install link** `rustic://content/rustic/<project>[?version=…]`: the launcher comes forward on the project page
  with an **install prompt** (target, version preselected, Install, Not now); nothing installs without the click.
- Building blocks for the next pages (Servers, Profiles): `apps/launcher/src/components/catalog/`.

#### 4.4.2 VPS sub-flow — [14-vps-install.svg](wireframes/14-vps-install.svg)

1. Connect: host, port (22), user, auth: **Generate a key for me** (recommended; shows the public key + a one-line
   command to add it, or "use my password once to add it": password not stored) / existing key file.
2. **Host key**: fingerprint shown "Compare with your provider's console" → Trust (pinned). A later mismatch blocks
   with a red warning and "I re-installed my VPS" path (re-pin after confirmation).
3. Preflight list (OS/arch supported, disk, RAM, systemd, firewall, port free) with fix hints.
4. Install progress (create `rustic` user, upload signed files, upload **your** game files from this PC, service +
   firewall, start and check). Each step: ✓ / … / ○ / ✕ with "Show log" and "Retry step".
5. Done → management page (same as local, labelled "My VPS (name)").

#### 4.4.3 Domain flow: three equal paths — [15](wireframes/15-domain-connect-porkbun.svg) · [16](wireframes/16-domain-buy.svg) · [17](wireframes/17-domain-byo-verify.svg)

Entry: "My own domain" offers three equal tiles: **Connect Porkbun** (automatic) · **Buy a domain at Porkbun**
(automatic) · **Use a domain from any registrar** (we show what to add and check it for you).

- **Connect Porkbun**: two short steps with links (create an API key at porkbun.com › Account › API Access; turn on
  "API Access" for the domain), fields API key + Secret key ("stored in your computer's keychain, never sent to
  Rustic"), Connect (ping) → domain picker → subdomain (default `play`) → **preview of the changes** (records to
  add/replace, dry run) → Apply → live verification panel (same as BYO) → Done.
- **Buy at Porkbun**: search box → results with availability, **first-year price and renewal price** as Porkbun quotes
  them (USD), "Taken" rows; Select → confirmation panel: seller is Porkbun (not Rustic), payment from the Porkbun
  account credit or saved card, two unticked checkboxes (Porkbun's registration agreement and terms; "Rustic sends this
  order to Porkbun on my behalf"), button "Buy at Porkbun · $X" (disabled until both ticked) → then the Connect path's
  Apply + verification automatically. Errors: price changed (re-quote), account not verified at Porkbun (link), TLD not
  available through the API, over $100.
- **Bring your own (any registrar)**: domain input, registrar picker (OVH, Gandi, Namecheap, GoDaddy, Cloudflare,
  Ionos, Hostinger, Porkbun manual, Other) showing a 3-5 line guide ("DNS zone → Add record → type CNAME…"); the
  **records table** for the case (CNAME to the relay, SRV `_minecraft._tcp` + target, or A/AAAA for a VPS, plus the
  TXT ownership record), each with **Copy** buttons per field; **live status per record**: Missing / Wrong value (shows
  found vs expected) / Propagating (n of 3 resolvers) / OK; "Checking automatically every 10 s · Check now"; when all
  OK: "Rustic Cloud verifies the TXT record, then your address starts working. You can close this; we'll notify you."

Help text (user-facing, EN source):
- "A domain is your server's address, like play.yourname.net. You can connect one you already have, buy one at Porkbun
  without leaving the launcher, or use any registrar: we show you exactly what to add."
- "Why a TXT record? It proves the domain is yours, so nobody else can point it at their server."
- "Changes can take from a minute to a few hours to reach everyone. We keep checking; you don't need to stay here."
- "Apex domains (yourname.net without 'play.') need an ALIAS/ANAME record; not every registrar has one. A subdomain
  always works."

### 4.8 Parental controls

Visible on accounts flagged as minor and to the linked parent (by email invite). Settings: purchases (off / ask a parent
/ allowed with monthly limit in €), chat (off / friends only), friend requests (off / friends of friends / everyone),
presence visibility, server hosting with public access (off by default for minors). PIN to change. Parent receives
purchase requests by email and approves in the web account page.

## 5. Key journeys

### J1. First launch — [13-first-launch.svg](wireframes/13-first-launch.svg)

1. Welcome (language auto-detected, changeable).
2. **Sign in with Microsoft** → browser → back to launcher ("You can close the browser tab"). Alternate: code on another
   device. Not owned → "You need Minecraft: Java Edition" with link; stop here.
3. **Rustic account**: "Continue with Microsoft" (opens the website, comes back through `rustic://auth`), or email + password (birth date) or Sign in, or **Skip for now** (game works;
   social, Locker, Store, servers' public access need it). Link of the MC profile happens silently.
4. **Privacy choices**: three telemetry toggles, all off; short plain-language text; Continue.
5. **Get the game ready**: finds the official launcher's files (or downloads Mojang files for this owner), downloads the
   Rustic edition, prepares; progress with steps; "You can explore meanwhile" (the shell becomes usable).
6. Home with PLAY ready. Total: ~5 screens, the long step runs in the background.

### J2. Play in ≤ 2 clicks

Launcher opens on the Launchpad with the last instance active → **click 1: LAUNCH** (hero); or Versions → play icon
on a cover (2 clicks). If an update is
pending, PLAY shows UPDATE: click 1 starts it and the game launches automatically when done (setting on by default).
Joining a friend: **click 1: Join** in the Launchpad friends column or the Social window (launches with `--server`).

### J3. Install a mod

1. Explore (or `Ctrl+K` "minimap") → Discover's rows, or type to land in Browse (Mods, compatible-only filter on).
2. Install on the row (target instance shown) → progress inline → "Installed ✓" + toast "Restart the game to use it"
   when the game is running.
3. Badges explain anything not Works before the click; Doesn't run is disabled.

### J4. Create a server and open it to the internet

1. Servers → **Create server** → Basics (Rustic Server, name, world, starter plugins, accept EULA) → Next.
2. Where to host: This PC → Next.
3. Access: Invite code on (default) + My own domain → **Connect Porkbun** (keys) → pick `loucraft.net`, sub `play` →
   preview → Apply → statuses turn OK → "Verified by Rustic Cloud" → Create.
